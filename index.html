04 — Process

How I build a website

My development approach, from the first requirement to the final fix.

  1. 01

    Understand the requirements

    Clarify the goal, the audience and what the page must do.

  2. 02

    Plan structure and user journey

    Turn site maps, user flows and wireframes into a clear page structure

  3. 03

    Establish the visual direction

    Choose type, colour and spacing so the interface feels consistent

  4. 04

    Develop the responsive interface

    Write semantic HTML and CSS that adapts from phone to desktop.

  5. 05

    Integrate application functionality

    Connect the interface to APIs, authentication and databases

  6. 06

    Test, debug and refine

    Check across devices, fix issues and tune performance.
